# MSP432 Line-Following Robot

基于 TI MSP432P401R 的循迹小车课程项目。

## 功能模块

- 红外循迹传感器读取
- 电机 PWM 驱动
- PID 闭环控制
- 定时器与延时
- 串口调试
- 按键输入与状态控制

## 源码结构

```text
src/        # 业务控制、传感器、电机、串口与 PID 模块
src/sys/    # 系统初始化与延时模块
```

## 开发环境

- MCU：MSP432P401R
- IDE：Keil MDK（课程工程）

## 第三方依赖

仓库不包含 TI DriverLib、CMSIS、编译产物和 IDE 缓存。请从 TI 官方渠道获取与 MSP432P401R 匹配的 SDK，并按工程配置添加依赖。

## 注意

引脚定义、供电和电机驱动必须与实际硬件一致。请在断开电机或抬起车轮的状态下完成初次调试。
